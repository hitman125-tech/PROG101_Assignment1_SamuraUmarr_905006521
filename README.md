SMART WASTE MANAGEMENT SYSTEM (SWMS)

1. Project Overview

The Smart Waste Management System (SWMS) is a proposed system designed to improve waste reporting and collection management in Freetown, Sierra Leone.

The system allows residents to report waste problems, administrators to verify reports and assign collection teams, and collection teams to update the progress of waste collection.

2. Aim of the Project

The main aim is to improve waste management through an organized digital reporting and monitoring system.

3. Main Users

* Residents: Submit waste reports and track their status.
* Administrators: Verify reports and assign collection teams.
* Collection Teams: Receive assignments and update collection progress.

4. Main Features

* Waste problem reporting.
* Location and waste category recording.
* Unique report identification numbers.
* Report verification by administrators.
* Collection team assignment.
* Waste collection status updates.
* Report tracking and summary generation.

5. Project Files

This repository contains:

* Assignment report.
* Algorithms and pseudocode documentation.
* Flowchart images showing the system processes.
* Project description and documentation.

8. Conclusion

The Smart Waste Management System demonstrates how computational thinking, algorithms, pseudocode and flowcharts can be used to design a solution to a real-world waste management problem in Sierra Leone.
